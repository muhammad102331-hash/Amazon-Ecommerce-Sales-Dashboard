# Amazon Sales Analysis Dashboard | Power BI

## 📌 Overview
This project is a **Power BI dashboard** analyzing Amazon product sales data for 2025.  
It provides actionable insights into:
- Total Sales, Completed, Pending, and Cancelled Orders
- Sales by Category and Product
- Payment Method Usage
- Order Status Distribution
- Customer Insights and Location-based Sales

![Dashboard](https://github.com/muhammad102331-hash/Amazon-Ecommerce-Sales-Dashboard/blob/main/SALES/dashboard.png)
## ✅ Features
✔ Interactive KPIs (Total Sales, Orders, Status)  
✔ Dynamic slicers for Date, Category, and Location  
✔ Drill-through for customer details  
✔ Professional dark theme with KPI cards  

## 📊 Visuals Included
- **Sales Trend by Month**
- **Sales by Category**
- **Top Products**
- **Order Status Distribution**
- **Payment Method Usage**
- **Sales by Location (Map)**

## 🛠 Tools Used
- Power BI Desktop
- DAX for KPIs
- Data Modeling & Visualization

## 📂 Dataset
Amazon sales transactions for 2025 (CSV format).
